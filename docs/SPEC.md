# ТЗ v1.1: тренажер слів NGSL

> v1.1 = вихідне ТЗ + покращення. Нове або змінене позначено **[нове]** / **[змінено]**.
> Обґрунтування змін — у розділі 11.

## 1. Мета

Вебзастосунок для одного користувача (рівень B1, рідна мова українська), щоб пройти NGSL: 2801 найуживаніше англійське слово. Мета — активний словник для розмови. Вчимо лише незнайомі слова й закріплюємо їх інтервальними повтореннями.

**Платформи [нове]:** мобільний браузер (Android, iOS) і десктоп. Встановлюється на головний екран як PWA і працює офлайн з першої версії.

## 2. Дані

Файл `data/ngsl-uk.tsv` (UTF-8, табуляція, з заголовком):

| Поле              | Опис                                                                  |
| ----------------- | --------------------------------------------------------------------- |
| `rank`            | 1–2801, частотний ранг (порядок проходження)                          |
| `word`            | англійське слово (базова форма)                                       |
| `translation`     | 1–3 основні значення українською через `,` / `;`                      |
| `example`         | коротке речення рівня A2–B1 зі словом                                 |
| `form` **[нове]** | точна форма слова в `example` (`duty → duties`, `accord → According`) |

- Слова діляться на **56 блоків**: 1–55 по 50 слів, блок 56 — 51 слово (ранги 2751–2801).
- **[нове] Валідація під час збірки** (збірка падає, якщо щось не так): 2801 рядок, ранги 1–2801 без пропусків, жодного порожнього поля, немає дублікатів `word`, `form` знаходиться в `example` як ціле слово.
- TSV — джерело правди. Скрипт збірки перетворює його в компактний JSON, який потрапляє в бандл і кешується офлайн.

## 3. Модель стану

### 3.1 Статуси

| Код             | Статус                  | Звідки потрапляє                           |
| --------------- | ----------------------- | ------------------------------------------ |
| `new`           | не відсортоване         | стан за замовчуванням                      |
| `known`         | знаю                    | сортування або ручне позначення            |
| `queued`        | у черзі на вивчення     | сортування («не знаю») або ручне додавання |
| `learning(1–4)` | на повторенні, етап 1–4 | після успішної перевірки у вивченні        |
| `mastered`      | вивчене                 | успішно пройдений етап 4                   |

### 3.2 Запис слова **[змінено]**

Зберігаються лише слова, що не `new` (розріджена мапа `rank → запис`):

```ts
type Status = 'known' | 'queued' | 'learning' | 'mastered';
interface WordState {
  s: Status;
  st?: 1 | 2 | 3 | 4; // етап для learning
  due?: number; // номер дня наступного повторення (див. 6.3)
  lapses?: number; // скільки разів «Забув» у повтореннях
  q?: number; // час ручного додавання в чергу (пріоритет)
  u: number; // updatedAt запису, мс — для синхронізації
}
```

- **[нове] Важкі слова:** `lapses ≥ 4` → слово позначається «важке» (фільтр у словнику, значок у картці).
- **[нове] Контрольне повторення:** після етапу 4 слово стає `mastered` і отримує `due` = +60 днів. «Згадав» → `due` знімається назавжди. «Забув» → `learning(1)`. Вимикається в налаштуваннях (за замовчуванням увімкнено).

## 4. Режими

### 4.1 Сортування

- Показується блок: 50 слів плитками. Тап — слово, якого **не знаю**, підсвічується. Повторний тап знімає позначку.
- Перемикач «Показати переклад» — для самоперевірки (переклад під словом у плитці).
- Лічильник «позначено N» і кнопка «Зберегти блок» (закріплена внизу).
- «Зберегти блок»: позначені слова стають `queued`, решта `known`. Потім автоматично відкривається наступний невідсортований блок.
- До збережених блоків можна повернутися й змінити вибір. Слова в `learning` і `mastered` заблоковані (показані приглушено з позначкою статусу).
- **[нове]** Перехід між блоками стрілками ← → (і свайпом на телефоні).

### 4.2 Вивчення нових

- Денний ліміт нових слів: 10 / 15 (за замовчуванням) / 20 / 25. Коли ліміт вичерпано — кнопка «Ще 5 слів» (+5 до ліміту на сьогодні).
- **[змінено] Порядок черги:** спершу слова, додані вручну зі словника (за часом додавання), далі — за рангом.
- Береться N слів (залишок ліміту на сьогодні) і ділиться на пачки по 5.
- Для кожної пачки:
  1. **Картки-знайомства**: слово, переклад, приклад із підсвіченим словом, озвучка (автоматично, якщо ввімкнено).
     **[нове]** Кнопка «Я це знаю» → слово стає `known`, замість нього в пачку додається наступне з черги.
  2. **Перевірка** тих самих 5 слів у випадковому порядку, напрямок UA→EN: переклад + приклад із пропуском (див. 6.1). «Показати» → слово, приклад повністю, озвучка → «Забув» / «Згадав».
- «Згадав»: слово стає `learning(1)`, `due` = завтра, лічильник нових за день +1.
- «Забув»: картка повертається в чергу через 4 позиції (якщо карток менше — у кінець) і повторюється, доки не буде «Згадав».
- Вихід посеред сесії нічого не ламає: пройдені слова вже в `learning(1)`, решта лишається `queued`.

### 4.3 Повторення

- Беруться слова з `due ≤ сьогодні`, спершу найбільш прострочені (далі — за рангом).
- **[нове] Раунди по 30 карток.** Після раунду — підсумок (згадав / забув) і кнопка «Ще N». Зручно для коротких сесій на телефоні.
- Напрямок картки:
  - етапи 1–2: EN→UA (слово + приклад → згадати значення);
  - етапи 3–4 і контрольне: UA→EN (переклад + приклад із пропуском → згадати слово).
- Інтервали: етап 1 → +3 дні → етап 2 → +7 → етап 3 → +21 → етап 4 → `mastered` (+60 контроль). Разом із першим днем: **1 / 3 / 7 / 21**.
- **[нове]** Інтервал рахується від дня фактичної відповіді, а не від `due`.
- «Забув»: етап 1, `due` = завтра, `lapses +1`. У поточній сесії картка показується ще раз через 4 позиції як вправа (без зміни статусу, до 3 спроб), у тому ж напрямку.

### 4.4 Спільне для сесій **[нове]**

- Смуга прогресу сесії, кнопка виходу, екран підсумку.
- **Скасувати останню відповідь** (кнопка ↶, клавіша `U`) — від випадкових тапів на телефоні. Відкочує стан слова, лічильники й чергу сесії.
- Кнопки «Забув» / «Згадав» — внизу екрана, в зоні великого пальця.

### 4.5 Словник

- Пошук англійською та українською: спершу слова, що починаються з запиту, потім ті, що містять. Без урахування регістру; **[нове]** апострофи `'`, `’`, `ʼ` вважаються однаковими.
- Фільтри: Усі / Вчу / Черга / Вивчено / Знаю / Не відсортовано / **[нове] Важкі**.
- Рядок: ранг, слово, переклад, статус. Розгортається: приклад, озвучка, дата наступного повторення, кількість помилок.
- Дії: «Я це знаю» (→ `known`), «Додати у вивчення» (→ `queued`, на початок черги), «Вчити з нуля» (з `learning`/`mastered` → `queued`, етап скидається).
- «Скопіювати слова, які вчу» — список `word — translation`.
  **[нове]** Друга кнопка «Скопіювати з промптом»: той самий список + готовий запит для AI-чату (напр., «Склади діалог на тему співбесіди з цими словами й перевіряй мої відповіді»).
- Список із 2801 рядка рендериться віртуально або порціями (швидко на телефоні).

## 5. Головний екран «Сьогодні»

Порядок блоків зверху вниз:

1. **Повторення** — скільки слів сьогодні (головна кнопка, пріоритет). **[нове]** Якщо прострочених > 50 — підказка «Спершу повторення» біля нових слів (не блокує).
2. **Нові слова** — вивчено X з ліміту.
3. Порожні стани:
   - черга порожня або менша за ліміт → «Відсортуй блок N» і кнопка переходу;
   - все повторено → коли наступне повторення («завтра, 12 слів»).
4. **Серія** днів поспіль з активністю.
5. **Прогрес:** відсоток `known + mastered` від 2801 і смуга за статусами з легендою.
6. **Прогноз повторень на 7 днів** (стовпчики; сьогодні включає прострочені).
7. **Карта 56 блоків:** у клітинці міні-смуга статусів; поточний блок (перший з `new`-словами) підсвічено; клік відкриває блок у сортуванні.

Налаштування — окремий екран (див. 7.4).

## 6. Допоміжна логіка

### 6.1 Пропуск у реченні **[змінено]**

- Використовується поле `form` з даних: у `example` замінюються **всі** входження `form` як цілого слова, без урахування регістру.
- Підказка: перша літера + `_` на кожну наступну літеру форми (`d _ _ _ _ _`). Для форм із 1–2 літер — `___`.
- Запасний алгоритм (для майбутніх власних слів без `form`): точний збіг → форми з суфіксами (`-s/-es/-ies/-ed/-ing`, випадання `-e`, подвоєння приголосної) → префікс.

### 6.2 Озвучка

- Web Speech API, голос `en-US`, швидкість 0.9, для прикладів 0.85. Якщо API чи англійського голосу немає — кнопки ховаються.
- **[нове]** Вибір найкращого доступного `en-US` голосу (з пріоритетом якісних/мережевих). На iOS автоозвучка стартує лише після першого тапу користувача (обмеження браузера).
- Автоозвучка (налаштування) — коли на екрані з'являється англійське слово.

### 6.3 Дата **[змінено]**

- Номер дня = кількість локальних календарних днів від 1970-01-01, без годин.
- **Новий день починається о 04:00** за локальним часом (як в Anki): заняття о 00:30 зараховуються до попереднього дня, серія не рветься.

### 6.4 Історія

- `{день: [нових, повторень, забув]}` **[змінено: + «забув»]**, зберігається 180 днів.
- Використовується для серії, прогнозу й статистики. Серія — дні поспіль (до сьогодні або вчора) з ≥ 1 відповіддю.

### 6.5 Гарячі клавіші в сесії

`Space`/`Enter` — показати або далі, `1` — забув, `2` — згадав, `Esc` — вийти, **[нове]** `U` — скасувати, `S` — озвучити.

### 6.6 Відмінки

`Intl.PluralRules('uk')`: 1 слово / 2 слова / 5 слів, 1 день / 2 дні / 5 днів.

## 7. Збереження і синхронізація

### 7.1 Стан

Один об'єкт:

```ts
interface AppState {
  v: number; // версія схеми (міграції)
  words: Record<number, WordState>; // лише не-new слова
  settings: Settings;
  history: Record<number, [number, number, number]>;
  today: { day: number; newDone: number; extra: number };
  updatedAt: number;
}
```

### 7.2 Локально

- **[змінено]** localStorage, синхронний запис після кожної відповіді: відповідь не губиться, навіть якщо закрити вкладку одразу після неї (асинхронний IndexedDB може не встигнути). Стан — до ~200 КБ при ліміті 5 МБ.
- **[нове]** `navigator.storage.persist()` — щоб браузер не видалив дані. Важливо для iOS: Safari може стерти дані сайту, який не відкривали 7 днів, якщо він **не** встановлений на головний екран → в UI підказка «Встанови на головний екран».
- **[нове]** Версія схеми + міграції, щоб оновлення застосунку не ламали прогрес.

### 7.3 Синхронізація телефон ↔ ПК **[змінено]**

- Сховище: приватний (secret) GitHub Gist з одним JSON-файлом. **[нове] Профілі:** кілька людей в одному GitHub-акаунті — у кожного імені профілю окремий Gist (`ngsl-trainer-progress-<імʼя латиницею>.json`). Токен (fine-grained, лише доступ до Gists) вводиться один раз на кожному пристрої. Бекенд не потрібен, історія ревізій Gist = безкоштовний бекап.
- **Злиття по словах**, а не всього об'єкта: для кожного слова перемагає запис із новішим `u`. Історія — максимум по кожному дню. Налаштування — новіший `updatedAt`. Так заняття офлайн на двох пристроях не губляться.
- Коли: завантаження при відкритті й при поверненні на вкладку; відправка через 5 с після змін і при згортанні вкладки. Статус синхронізації видно в налаштуваннях.

### 7.4 Налаштування

Денний ліміт, автоозвучка, тема (система / світла / темна), контрольне повторення, синхронізація, експорт / імпорт JSON (імпорт: «об'єднати» або «замінити» з підтвердженням), скидання прогресу (з підтвердженням).

## 8. UI/UX

- Mobile-first (від 360 px), одна колонка, зони натискання ≥ 44 px, кнопки відповіді внизу.
- **[нове]** Навігація: на телефоні — нижня панель (Сьогодні / Сортування / Словник / Налаштування), на десктопі — верхня; у сесії навігація схована. Відступи під «чубчик» і жестову панель (safe-area).
- Світла й темна теми (за замовчуванням — як у системі).
- Шрифти: із засічками для англійських слів (словниковий вигляд), без засічок для інтерфейсу, моноширинний для цифр. **[нове]** Шрифти вбудовані в застосунок (працюють офлайн).
- Семантичні кольори: знаю — зелений; вчу — бурштиновий; черга — червоний; вивчено — акцентний синій; **[нове]** не відсортовано — сірий.
- Мікроанімації: перевертання / поява відповіді, прогрес сесії. Поважати `prefers-reduced-motion`.
- Інтерфейс українською, правильні відмінки.
- **[нове]** Доступність: контраст AA, фокус видно, озвучення відповіді для скрінрідерів (`aria-live`).

## 9. Що додати у v2

- Транскрипція (IPA) — автоматично з CMUdict, частина мови — з ручною перевіркою.
- 2–3 приклади на слово з перекладом речень.
- Режим «надрукуй слово» для етапу 4 (UA→EN з перевіркою написання й допуском на 1 помилку).
- Тема дня або набори слів під рекрутинг (інтерв'ю, зарплата, досвід).
- Щоденне нагадування (Web Push; на iOS — лише для встановленої PWA, iOS 16.4+).
- Статистика: теплова карта активності, точність за етапами, найважчі слова.
- Власна нотатка / асоціація до важкого слова.

## 10. Критерії готовності

- Усі 2801 слово завантажуються з TSV, блоки й ранги правильні, валідація даних проходить.
- Повний цикл працює: сортування → вивчення → повторення через 1/3/7/21 → `mastered` → контроль через 60; «Забув» повертає на етап 1.
- Скасування останньої відповіді працює в обох сесіях.
- Стан переживає перезавантаження сторінки й роботу офлайн.
- Синхронізація: зміни з телефону видно на ПК після повернення на вкладку; заняття офлайн на двох пристроях зливаються без втрат.
- Коректно виглядає на 360 px і на десктопі, в обох темах.
- Сесія повністю проходиться з клавіатури.
- Застосунок встановлюється як PWA (Android, iOS, десктоп Chrome).
- Автотести: логіка (планувальник, пропуск на всіх 2801 прикладі, відмінки, злиття) і e2e на 360 px та 1280 px.

**Стек:** React + TypeScript + Vite, Tailwind, Zustand + localStorage, vite-plugin-pwa, власний hash-роутер (для GitHub Pages), Vitest, Playwright. Графіки — простий SVG/CSS без бібліотек. Хостинг — GitHub Pages через GitHub Actions.
