# План реалізації

Три віхи. Після **М1** вже можна щодня вчитися з телефону.

| Віха                   | Що дає                                                                   | Етапи |
| ---------------------- | ------------------------------------------------------------------------ | ----- |
| **М1 «Можна вчитись»** | Сортування, вивчення, повторення, базовий «Сьогодні», офлайн на телефоні | 0–8   |
| **М2 «Два пристрої»**  | Синхронізація телефон ↔ ПК, словник, експорт/імпорт                      | 9–10  |
| **М3 «Полірування»**   | Повний дашборд, анімації, e2e-тести, реліз 1.0                           | 11–12 |

> Поки немає синхронізації (М2), вчитися лише на одному пристрої — щоб не розщепити прогрес.

## Структура проєкту

```
data/ngsl-uk.tsv           джерело даних
scripts/vite-plugin-ngsl.ts  TSV → модуль virtual:ngsl-words + валідація під час збірки
src/core/                  чиста логіка без UI (+ тести поруч)
src/store/                 Zustand, IndexedDB, міграції
src/sync/                  Gist-синхронізація, злиття
src/ui/                    спільні компоненти
src/features/              today, sort, learn, review, dictionary, settings
e2e/                       Playwright
docs/                      SPEC.md, PLAN.md
```

## М1 «Можна вчитись»

### Етап 0. Інфраструктура

- [x] Vite + React + TypeScript, Tailwind, ESLint + Prettier.
- [x] Vitest, Playwright (профілі 360×740 і 1280×800).
- [x] GitHub Actions: lint → typecheck → test → build → e2e → деплой на GitHub Pages.
- **Готово, коли:** порожній застосунок відкривається за посиланням на телефоні.

### Етап 1. Дані

- [x] Vite-плагін `scripts/vite-plugin-ngsl.ts`: TSV → модуль `virtual:ngsl-words` (компактні масиви), валідація з SPEC §2.
- [x] Тест: 2801 рядок, 56 блоків (останній — 51), `form` є в кожному прикладі, запасний алгоритм дає ту саму форму.
- **Готово, коли:** збірка падає на зіпсованому TSV і проходить на чистому.

### Етап 2. Доменна логіка (`src/core`, без UI)

- [x] `dates` — номер дня з межею о 04:00.
- [x] `plural` — відмінки (uk).
- [x] `cloze` — пропуск і підказка за `form`.
- [x] `scheduler` — переходи статусів: сортування, «Згадав» / «Забув», 1/3/7/21, `mastered`, контроль +60, `lapses`.
- [x] `session` — черга сесії: пачки по 5, повернення через 4 позиції, практика до 3 спроб, раунди по 30. (Стек скасування — у сторі, етап 3.)
- [x] `stats` — прогрес, серія, прогноз на 7 днів, статуси блоків.
- **Готово, коли:** тест «прожив» повний цикл слова зі штучною датою: `new → queued → learning(1..4) → mastered → контроль`, плюс «Забув» на кожному етапі.

### Етап 3. Стан і збереження

- [x] Zustand-стор, синхронне збереження в localStorage після кожної відповіді (IndexedDB асинхронний — відповідь могла загубитися при закритті вкладки).
- [x] `navigator.storage.persist()`, версія схеми + міграції, синхронізація між вкладками.
- [x] Стек скасування відповідей (до 50 кроків у сесії).
- **Готово, коли:** прогрес переживає перезавантаження.

### Етап 4. Каркас UI

- [x] Маршрути (власний hash-роутер): Сьогодні / Сортування / Налаштування / Сесія. Словник — етап 10.
- [x] Нижня навігація (телефон) / верхня (десктоп), safe-area.
- [x] Теми світла / темна / система, дизайн-токени з семантичними кольорами.
- [x] Шрифти локально: засічковий (EN-слова), без засічок (UI), моноширинний (цифри).
- [x] Базові компоненти: кнопка, картка, смуга статусів, перемикач, діалог підтвердження.

### Етап 5. Сортування

- [x] Сітка 50 плиток, тап = «не знаю», перемикач перекладу, лічильник.
- [x] «Зберегти блок» → автоперехід до наступного; стрілки / свайп між блоками.
- [x] Заблоковані `learning` / `mastered`.

### Етап 6. Сесія вивчення нових

- [x] Спільна оболонка сесії: прогрес, вихід, скасування, гарячі клавіші, екран підсумку.
- [x] Картки-знайомства + «Я це знаю», автоозвучка.
- [x] Перевірка UA→EN з пропуском; денний ліміт і «Ще 5 слів».

### Етап 7. Сесія повторення

- [x] Прострочені першими, раунди по 30, напрямок за етапом.
- [x] «Забув» → етап 1 + практика в сесії.

### Етап 8. «Сьогодні» (базовий) + PWA

- [x] Картки «Повторення» і «Нові слова», порожні стани, серія, відсоток прогресу.
- [x] Налаштування: ліміт, автоозвучка, тема.
- [x] vite-plugin-pwa: маніфест, іконки, офлайн-кеш даних і шрифтів; підказка «Встанови на головний екран» (особливо для iOS).
- **Готово (М1), коли:** на телефоні можна встановити застосунок і пройти сортування → вивчення → повторення офлайн.

## М2 «Два пристрої»

- [ ] Пошук EN/UA (спершу «починається з»), фільтри, включно з «Важкі».
- [ ] Розгорнутий рядок: приклад, озвучка, дата повторення, помилки.
- [ ] Дії: «Я це знаю», «Додати у вивчення», «Вчити з нуля».
- [ ] «Скопіювати слова, які вчу» (+ варіант із промптом для AI).
- [ ] Віртуальний список (швидко на 2801 рядку).
