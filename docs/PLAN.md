# План реалізації

Три віхи. Після **М1** вже можна щодня вчитися з телефону.

| Віха | Що дає | Етапи |
|---|---|---|
| **М1 «Можна вчитись»** | Сортування, вивчення, повторення, базовий «Сьогодні», офлайн на телефоні | 0–8 |
| **М2 «Два пристрої»** | Синхронізація телефон ↔ ПК, словник, експорт/імпорт | 9–10 |
| **М3 «Полірування»** | Повний дашборд, анімації, e2e-тести, реліз 1.0 | 11–12 |

> Поки немає синхронізації (М2), вчитися лише на одному пристрої — щоб не розщепити прогрес.

## Структура проєкту
```
data/ngsl-uk.tsv           джерело даних
scripts/build-data.ts      TSV → JSON + валідація
src/core/                  чиста логіка без UI (+ тести поруч)
src/store/                 Zustand, IndexedDB, міграції
src/sync/                  Gist-синхронізація, злиття
src/ui/                    спільні компоненти
src/features/              today, sort, learn, review, dictionary, settings
e2e/                       Playwright
docs/                      SPEC.md, PLAN.md
```

## М1 «Можна вчитись»

### Етап 0. Інфраструктура
- [ ] Vite + React + TypeScript, Tailwind, ESLint + Prettier.
- [ ] Vitest, Playwright (профілі 360×740 і 1280×800).
- [ ] GitHub Actions: lint → typecheck → test → build → деплой на GitHub Pages.
- **Готово, коли:** порожній застосунок відкривається за посиланням на телефоні.

### Етап 1. Дані
- [ ] `scripts/build-data.ts`: TSV → `src/data/words.json` (компактні масиви), валідація з SPEC §2.
- [ ] Тест: 2801 рядок, 56 блоків (останній — 51), `form` є в кожному прикладі.
- **Готово, коли:** збірка падає на зіпсованому TSV і проходить на чистому.

### Етап 2. Доменна логіка (`src/core`, без UI)
- [ ] `dates` — номер дня з межею о 04:00.
- [ ] `plural` — відмінки (uk).
- [ ] `cloze` — пропуск і підказка за `form`.
- [ ] `scheduler` — переходи статусів: сортування, «Згадав» / «Забув», 1/3/7/21, `mastered`, контроль +60, `lapses`.
- [ ] `session` — черга сесії: пачки по 5, повернення через 4 позиції, практика до 3 спроб, раунди по 30, стек скасування.
- [ ] `stats` — прогрес, серія, прогноз на 7 днів, статуси блоків.
- **Готово, коли:** тест «прожив» повний цикл слова зі штучною датою: `new → queued → learning(1..4) → mastered → контроль`, плюс «Забув» на кожному етапі.

### Етап 3. Стан і збереження
- [ ] Zustand-стор, збереження в IndexedDB після кожної відповіді.
- [ ] `navigator.storage.persist()`, версія схеми + міграції.
- **Готово, коли:** прогрес переживає перезавантаження.

### Етап 4. Каркас UI
- [ ] Маршрути: Сьогодні / Сортування / Словник / Налаштування / Сесія.
- [ ] Нижня навігація (телефон) / верхня (десктоп), safe-area.
- [ ] Теми світла / темна / система, дизайн-токени з семантичними кольорами.
- [ ] Шрифти локально: засічковий (EN-слова), без засічок (UI), моноширинний (цифри).
- [ ] Базові компоненти: кнопка, картка, смуга статусів, перемикач, діалог підтвердження.

### Етап 5. Сортування
- [ ] Сітка 50 плиток, тап = «не знаю», перемикач перекладу, лічильник.
- [ ] «Зберегти блок» → автоперехід до наступного; стрілки / свайп між блоками.
- [ ] Заблоковані `learning` / `mastered`.

### Етап 6. Сесія вивчення нових
- [ ] Спільна оболонка сесії: прогрес, вихід, скасування, гарячі клавіші, екран підсумку.
- [ ] Картки-знайомства + «Я це знаю», автоозвучка.
- [ ] Перевірка UA→EN з пропуском; денний ліміт і «Ще 5 слів».

### Етап 7. Сесія повторення
- [ ] Прострочені першими, раунди по 30, напрямок за етапом.
- [ ] «Забув» → етап 1 + практика в сесії.

### Етап 8. «Сьогодні» (базовий) + PWA
- [ ] Картки «Повторення» і «Нові слова», порожні стани, серія, відсоток прогресу.
- [ ] Налаштування: ліміт, автоозвучка, тема.
- [ ] vite-plugin-pwa: маніфест, іконки, офлайн-кеш даних і шрифтів; підказка «Встанови на головний екран» (особливо для iOS).
- **Готово (М1), коли:** на телефоні можна встановити застосунок і пройти сортування → вивчення → повторення офлайн.

## М2 «Два пристрої»

### Етап 9. Синхронізація
- [ ] Налаштування: вставити токен, створити / знайти приватний Gist.
- [ ] Злиття по словах за `u`, історія — максимум по днях (юніт-тести на конфлікти).
- [ ] Коли синхронізувати: відкриття, повернення на вкладку, 5 с після змін, згортання. Статус і час останньої синхронізації.
- [ ] Експорт / імпорт JSON (об'єднати / замінити).

### Етап 10. Словник
- [ ] Пошук EN/UA (спершу «починається з»), фільтри, включно з «Важкі».
- [ ] Розгорнутий рядок: приклад, озвучка, дата повторення, помилки.
- [ ] Дії: «Я це знаю», «Додати у вивчення», «Вчити з нуля».
- [ ] «Скопіювати слова, які вчу» (+ варіант із промптом для AI).
- [ ] Віртуальний список (швидко на 2801 рядку).

## Потрібні рішення від тебе
1. **Хостинг.** GitHub Pages безкоштовно працює лише з **публічним** репозиторієм (для приватного потрібен GitHub Pro). Варіанти: публічний репо + Pages *(рекомендую — у репо немає нічого особистого)* або приватний репо + Cloudflare Pages / Vercel (потрібен акаунт там).
2. **Синхронізація.** GitHub Gist *(рекомендую — без бекенду, безкоштовно)* або Supabase (надійніше, але окремий акаунт і налаштування).
